Safety System Integration for Automobiles

This is my Internet of Things project for 2nd year. It aims to provide older vehicles with new satefy sytems to ensure a more safe and comfortable journey.

Currently features:

  • A server hosted website with real time data from the micro-controllers.
  • Distance sensor with audio cues to indicate distance
  • Alcohol sensor, with notifications
  • Temperature and humidity sensor
  • GPS sensor with current loction and google maps
  • A camera with real-time feed
  • Heart rate and blood oxygen monitor
  • Rfid locking system
